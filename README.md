## 🚀 Featured Projects

### ⚡ SkillBridge AI — AI Career Intelligence Platform

<div align="center">
  
[![Repo](https://img.shields.io/badge/View_Repository-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Tahirahmad1002/skillbridge-ai)

</div>

> AI-powered platform that analyzes a resume against any job description to identify skill gaps and generate personalized career roadmaps using semantic embeddings and Groq LLM.

**Highlights:**
- 🧠 **Semantic skill matching** using Sentence Transformers (all-MiniLM-L6-v2)
- 🎯 **Explainable readiness scoring** with matched/partial/missing breakdown
- 🗺️ **AI-generated roadmaps** via 2-call Groq LLM pipeline
- 💬 **RAG-based chatbot** that knows the user's specific profile
- 🎨 **Premium UI** with Streamlit + custom CSS

**Tech:** `Python` `FastAPI` `Streamlit` `Groq` `Sentence Transformers` `BeautifulSoup`
